# pdd-frontend

Стек:
- Vue 3
- TypeScript
- Vite
- Tailwind CSS v4
- Pinia

## Описание

Адаптивный интерактивный компонент «Плеер решения билета ПДД».

## Функциональность

- навигация 1–20;
- выбор ответа;
- correct/incorrect;
- избранное;
- изображения;
- 3D-Видеоразбор / Paywall;
- responsive mobile/desktop.

## Источник данных

https://github.com/etspring/pdd_russia

`src/data/ticket-1.json` соответствует исходному `Билет 1.json`.

## Команды

```bash
npm install
npm run dev
npm run build
```
